# FIFTEEN
A sliding tile puzzle for Medley InterLisp: https://interlisp.org/


To use this program simply save the files to a location which Medley can access.
DO NOT just copy and paste the contents. They contain special characters for Medley only.

For me on Linux this is $HOME/il

Right Click the Medley Desktop and select "Interlisp" from the EXEC option.
From there type in (LOAD "FIFTEEN.LISP") .
Run the game by typing (START-FIFTEEN). You can optionally set the column and row count as parameters - (START-FIFTEEN 5 6) for example.

You can also view the manual in TEdit by typing (TEDIT "FIFTEEN.TEDIT")
